# Contribuer

- `main` reste compilable.
- Une fonctionnalité = une branche `feature/...`.
- Toute nouvelle commande OnStep doit être ajoutée au repository/protocole, jamais directement dans un écran Compose.
- Ajouter au moins un test lorsque le parsing d'une réponse OnStep change.
- Les mouvements réels doivent conserver un STOP global accessible.
